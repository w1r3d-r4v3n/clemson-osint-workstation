OSINT Launchpad

Plan deliberately. Collect minimally. Preserve provenance. Report uncertainty.

Isolation is not anonymity. This VM uses the same public internet connection unless you deliberately use a separate, lawful traffic path. Never mix identifying accounts with a separated research profile.

Start with the workflow

  1. FrameQuestion, authority, scope, stopping rule
  2. PlanKeywords, identifiers, source classes, risks
  3. DiscoverBroad search; record leads, not conclusions
  4. VerifyCorroborate identity, date, place, and context
  5. PreserveSource URL, UTC time, original file, SHA-256
  6. AnalyzeSeparate observations, inference, and gaps
  7. ReportCite sources; minimize personal data; peer review

Before opening a sensitive source

1. Is access lawful?Publicly reachable is not the same as authorized reuse. Stop at login walls, paywalls, and technical controls.
2. Is collection necessary?Gather only what answers the scoped question. Do not build gratuitous dossiers.
3. Could you expose a person?Minimize personal data, redact reports, and escalate credible safety concerns to the instructor.
4. What identity is in use?Do not sign in to personal or Clemson accounts from a separated research profile.
